# Vasilisk Dev

Полная сборка **Vasilisk Virtual Studio** — студии, где свой ИИ собирают, учат и запускают прямо на маке. Устроена как
музыкальная студия: модель — дорожка, её версии — клипы, а цепочка устройств (данные → основа → характер →
обучение → генерация → эффекты → оценка) — то, через что проходит ответ.

### [⬇ Скачать Vasilisk Dev 0.9.1](https://github.com/VasiliskStudio/vasilisk-dev/releases/latest)

Бесплатно: все версии до 1.0 бесплатны. Код частично закрыт; открытая часть — [Vasilisk X](https://github.com/VasiliskStudio/vasilisk-x)
(MPL 2.0). Условия — [EULA.md](EULA.md).

## Что умеет

- **Текст.** Модели на этом маке (llama.cpp, mlx) и Groq по своему ключу, «Характер», ручки генерации, эффекты,
  версии и сборки.
- **Обучение.** Датасеты из разговоров и файлов, дообучение LoRA на mlx, обучение на предпочтениях, своя маленькая
  модель с нуля, экспорт в GGUF, Q4 и Ollama.
- **Оценка.** Судья, сравнение вслепую, «Под капотом» — вероятности, внимание и числа под словами.
- **Картинки и видео.** Stable Diffusion 1.5 со своим стилем, ролики AnimateDiff, своя видеомодель с нуля.
- **Музыка.** MusicGen по описанию и продолжение своего трека, дообучение на своих треках, своя музыкальная модель.
- **И ещё.** «Знания» по своим документам, таблицы, экран «Мозг» — живая картина ответа, «Оформление», генератор
  примеров, поиск моделей на Hugging Face, Vasilisk DS.
- **Надёжность.** Снимки проекта, предохранитель памяти, «Жалоба».

Чем отличается от открытой Vasilisk X: в X нет видео, «Мозга», «Оформления», генератора примеров, поиска на
Hugging Face, внимания в «Под капотом» и кнопок Vasilisk DS.

## Установка

1. Нужен мак на Apple Silicon (M1 и новее), macOS 14 или новее, от 8 ГБ памяти.
2. Скачай `Vasilisk-Dev-0.9.1.dmg` со [страницы релизов](https://github.com/VasiliskStudio/vasilisk-dev/releases/latest),
   открой его и перетащи «Vasilisk Dev» в «Программы».
3. Сборка не подписана сертификатом Apple, поэтому при первом запуске нажми правой кнопкой по приложению →
   «Открыть» → «Открыть». Если macOS пишет «повреждено», выполни в Терминале:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Vasilisk Dev.app"
   ```

4. Модели и окружения Python скачиваются кнопками в самом приложении, всё складывается в `~/Vasilisk`.

## Важно

- Скачивай Vasilisk Dev только со страниц релизов VasiliskStudio; пересылать сам файл нельзя — делись ссылкой.
- Пользоваться можно для любых целей, в том числе для заработка. Но у моделей свои лицензии: **MusicGen и EnCodec —
  только для некоммерческого использования.**
- Программа даётся «как есть»: делай снимки проектов.
- Нашёл ошибку — нажми «Жалоба» в приложении (журналы сложатся в папку на маке) и опиши её в
  [Issues](https://github.com/VasiliskStudio/vasilisk-dev/issues).

«Vasilisk» и знак √S — название и знак проекта; см. [NOTICE](https://github.com/VasiliskStudio/vasilisk-x/blob/main/NOTICE.md).
